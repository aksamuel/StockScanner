StockScanner stable release 2.12.0

This package has been prepared for stable production release version 2.12.0.

Key details:
- Package name: stockscanner
- Version: 2.12.0
- Entry points:
  - stockscanner = stockscanner.cli:main
  - download-nyse = download_nyse:main
- Dependencies:
  - pandas
  - numpy
  - yfinance
  - ta
  - openpyxl
  - openai
  - python-dotenv
- Development dependencies:
  - pytest

Install locally with:
  .venv\Scripts\python.exe -m pip install -e .

Run the scanner with:
  .\run.bat

Production baseline:
  - Branch: main
  - Stable branch: stable/v2.12.0
  - Release verification: 96 tests passed

Production data:
  - Latest NYSE ticker universe: public.nyse_tickers in Supabase
  - Latest hourly prices: public.price_snapshots in Supabase
  - No market-data snapshot history is retained

Production workflows:
  - Daily NYSE ticker refresh at 8:00 AM New York time
  - Full scanner and GitHub Pages deployment at 13:00 UTC on weekdays
  - Hourly price refresh during weekday market hours

Authentication and personal data:
  - New accounts require administrator permission
  - Admin pages are restricted to aaksamuel@zohomail.com
  - Exception and bought-selection rows are private to each user
  - Bought selections show current profit/loss percentages
  - Bought selections show time-to-profit status and benchmark breakeven scenarios
  - Protected-page navigation uses a responsive collapsible left drawer
  - KPI cards open searchable category stock lists
  - Deleting a user cascades deletion of their personal lists
