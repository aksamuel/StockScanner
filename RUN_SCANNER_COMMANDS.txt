How to run StockScanner from Command Prompt

From C:\StockScanner:

Note: if global python is not available, always use .venv\Scripts\python.exe from the repo root.


== RECOMMENDED: Full NYSE scan with HTML dashboard ==

cd /d C:\StockScanner
.venv\Scripts\python.exe -m stockscanner.cli --universe --force-download --parallel --workers 20 --html


== Watchlist scan with HTML dashboard ==

cd /d C:\StockScanner
.venv\Scripts\python.exe -m stockscanner.cli --parallel --workers 20 --html


== NYSE scan with batch Excel reports + HTML dashboard ==

cd /d C:\StockScanner
.venv\Scripts\python.exe -m stockscanner.cli --universe --force-download --batch-reports --parallel --workers 20 --html


== Quick test run (limited tickers) ==

cd /d C:\StockScanner
.venv\Scripts\python.exe -m stockscanner.cli --universe --limit 20 --parallel --workers 20 --html --progress


== Custom position sizing ==

cd /d C:\StockScanner
.venv\Scripts\python.exe -m stockscanner.cli --universe --parallel --workers 20 --html --portfolio 100000 --position-size 5 --risk 1

  --portfolio 100000    Total portfolio value ($100,000)
  --position-size 5     Max 5% of portfolio per position ($5,000)
  --risk 1              Risk 1% per trade ($50)


== Conservative position sizing ==

cd /d C:\StockScanner
.venv\Scripts\python.exe -m stockscanner.cli --universe --parallel --workers 20 --html --portfolio 50000 --position-size 2 --risk 1


== Excel report only (no HTML) ==

cd /d C:\StockScanner
.venv\Scripts\python.exe -m stockscanner.cli --universe --parallel --workers 20


== Console output only (no reports) ==

cd /d C:\StockScanner
.venv\Scripts\python.exe -m stockscanner.cli --universe --limit 10 --no-report


== Using the batch launcher ==

cd /d C:\StockScanner
run.bat --universe --force-download --parallel --workers 20 --html


== Download NYSE tickers only ==

cd /d C:\StockScanner
download_nyse.bat --force-download


== View help ==

cd /d C:\StockScanner
.venv\Scripts\python.exe -m stockscanner.cli --help
