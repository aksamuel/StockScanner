StockScanner v2.13.0 command reference

Run commands from C:\StockScanner. If global Python is unavailable, use
.venv\Scripts\python.exe as shown below.


== RECOMMENDED LOCAL FULL NYSE SCAN ==

cd /d C:\StockScanner
.venv\Scripts\python.exe -m stockscanner.cli --universe --universe-source download --parallel --workers 20 --html


== PRODUCTION-STYLE SCAN USING SUPABASE ==

SUPABASE_URL and SUPABASE_SECRET_KEY must already be set securely in the current
session. Never save the secret key in this file or any source-controlled file.

cd /d C:\StockScanner
.venv\Scripts\python.exe -m stockscanner.cli --universe --universe-source supabase --parallel --workers 20 --html


== WATCHLIST SCAN WITH HTML DASHBOARD ==

cd /d C:\StockScanner
.venv\Scripts\python.exe -m stockscanner.cli --parallel --workers 20 --html


== NYSE SCAN WITH BATCH EXCEL REPORTS AND HTML ==

cd /d C:\StockScanner
.venv\Scripts\python.exe -m stockscanner.cli --universe --universe-source download --batch-reports --parallel --workers 20 --html


== QUICK LOCAL TEST ==

cd /d C:\StockScanner
.venv\Scripts\python.exe -m stockscanner.cli --universe --universe-source download --limit 20 --parallel --workers 5 --html --progress


== CUSTOM POSITION SIZING ==

cd /d C:\StockScanner
.venv\Scripts\python.exe -m stockscanner.cli --universe --universe-source download --parallel --workers 20 --html --portfolio 100000 --position-size 5 --risk 1

  --portfolio 100000    Total portfolio value ($100,000)
  --position-size 5     Maximum 5% of portfolio per position
  --risk 1              Maximum 1% portfolio risk per trade


== CONSERVATIVE POSITION SIZING ==

cd /d C:\StockScanner
.venv\Scripts\python.exe -m stockscanner.cli --universe --universe-source download --parallel --workers 20 --html --portfolio 50000 --position-size 2 --risk 1


== EXCEL REPORT ONLY ==

cd /d C:\StockScanner
.venv\Scripts\python.exe -m stockscanner.cli --universe --universe-source download --parallel --workers 20


== CONSOLE OUTPUT ONLY ==

cd /d C:\StockScanner
.venv\Scripts\python.exe -m stockscanner.cli --universe --universe-source download --limit 10 --no-report


== USING THE WINDOWS LAUNCHER ==

cd /d C:\StockScanner
run.bat --universe --universe-source download --parallel --workers 20 --html


== REFRESH LEGACY LOCAL CSV ONLY ==

cd /d C:\StockScanner
download_nyse.bat --force-yfinance

Production does not read this CSV. The Daily NYSE Ticker Universe GitHub
workflow writes the current universe to public.nyse_tickers in Supabase.


== RUN ALL TESTS ==

cd /d C:\StockScanner
.venv\Scripts\python.exe -m pytest -q


== VIEW CLI HELP ==

cd /d C:\StockScanner
.venv\Scripts\python.exe -m stockscanner.cli --help
