Portfolio analysis and human review

Connect this page to a deployed PIP API to import CSV/Flex exports, load available Yahoo research and shared market prices, persist portfolio analysis, and review auditable recommendations. Market facts are displayed with their sources; PIP does not invent score conversions for raw returns.

No live IBKR connection or order transmitter is available. CSV imports and analysis are saved only after you connect an API and explicitly submit them. Approval records a human decision; it does not submit an order.
