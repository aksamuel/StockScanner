Run the PIP modules on your saved holdings

This page connects to your PIP API, lists the holdings saved in your portfolio, and runs one analysis module when you press its button. The optional inputs let you try "what if" values; they are used for that run only.

Read-only. Nothing is saved and no orders are placed. To import files, sync IBKR Flex, or record an approval decision, use the PIP workbench.

Connect to the PIP API

The default PIP API is pre-filled and connects automatically after you sign in. You can use another deployment; the address is saved in this browser only. Your sign-in token is sent to this address, so use only a service you trust.
