StockScanner stable release 2.13.0

This package has been prepared for stable production release version 2.13.0.

Key details:
- Package name: stockscanner
- Version: 2.13.0
- Entry points:
  - stockscanner = stockscanner.cli:main
  - download-nyse = download_nyse:main
- Dependencies:
  - pandas
  - numpy
  - yfinance
  - ta
  - openpyxl
  - openai
  - python-dotenv
- Development dependencies:
  - pytest

Install locally with:
  .venv\Scripts\python.exe -m pip install -e .

Run the scanner with:
  .\run.bat

Production baseline:
  - Branch: main
  - Stable branch: stable/v2.13.0
  - Release label: v2.13.0
  - Release verification: 113 tests passed

Production data:
  - Latest NYSE ticker universe: public.nyse_tickers in Supabase
  - Latest hourly prices: public.price_snapshots in Supabase
  - No market-data snapshot history is retained

Production workflows:
  - Daily NYSE ticker refresh at 8:07 AM New York time
  - Full scanner and GitHub Pages deployment at 9:17 AM New York time
  - Hourly price refresh during weekday market hours

Authentication and personal data:
  - New accounts require administrator permission
  - Admin pages are restricted to aaksamuel@zohomail.com
  - Exception, bought-selection, and portfolio rows are private to each user
  - Deleting a user cascades deletion of their personal lists and portfolio
  - Protected-page navigation uses a responsive collapsible left drawer
  - KPI cards open searchable category stock lists

Portfolio analysis in v2.13.0:
  - Action review appears next to Symbol and Broker is the final data column
  - Profit review begins at a 7% return instead of 20%
  - A manual target overrides automatic target selection
  - Automatic targets use the closest valid profit-side value from the 7%
    return objective, Technical Target 1, technical resistance, and the analyst
    target proxy
  - A reached target creates a review signal only; no trade is submitted
